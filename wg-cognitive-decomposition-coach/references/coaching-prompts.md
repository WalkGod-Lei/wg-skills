# 追问、提示与模式切换

问题库不是检查清单。先判断瓶颈，再选择一种回复模式；每轮只让用户完成一个相邻动作。

## 五级提示

### Level 0：纯提问

- “如果只保留确定知道的事实，还剩下什么？”
- “这一步为什么能推出下一步？”
- “同一个结果还有什么不同解释？”
- “什么观察会让你修改这个判断？”

适用：用户已有知识和思考空间，只需要聚焦。

### Level 1：单一方向

- “先只看时间因素：长期背景和短期触发是否不同？”
- “先区分主观动机与客观受益。”
- “可以从平台自身的成本或激励想一个变量。”

适用：用户略卡，但给一个维度就能继续。

### Level 2：候选脚手架

给出 2—3 个不预设排名的候选，再让用户比较：

> 这里至少可以从降低冲突、降低审核成本、维持既有目标三个方向理解。它们可能并存，也可能只有一个更关键。哪一个最能解释你观察到的具体处理方式？

适用：用户明确想不到或缺少背景知识。候选必须有差异，不能只是同义改写。

### Level 3：局部机制图

补齐当前一层的结构，例如：

> 参与者 A 的目标 → 约束/激励 → 采用机制 B → 产生直接结果 C → 反馈到下一轮行为。

然后让用户检查其中最弱的一条箭头，或补一个竞争机制。不要顺带完成整场分析。

### Level 4：完整分析

只在用户明确要求、训练结束或必须系统纠正时使用。按事实、用户模型、候选动机、机制、触发、遗漏变量、替代解释、证据边界和有条件结论组织。

## 明确的切换触发词

出现以下意思时，当轮就从纯追问切换到 Level 2 或 3：

- “我想不到了。”
- “我不太清楚，需要你补充。”
- “给点看法/介绍一下。”
- “我的资料工具主要是 AI。”
- “你的作用是帮我扩展知识面。”

不要先再问一轮“你真的想不到别的吗”。若用户已有一个模型但没有候选解释，先供给候选；若缺的是外部证据，切换研究模式。

## 四种可见回复模板

### 提问轮

> 你已经区分了现象和解释，但把客观效果直接推成了主观设计。
>
> 中间还需要哪一种可观察机制，才能把两者连接起来？

### 脚手架轮

> 你现在缺的不是继续表态，而是可比较的解释框架。
>
> 可以先看三个方向：行动者自己的风险规避、规则执行的扩大化、以及更上层目标带来的间接约束。它们都可能造成相似结果，但动机不同。
>
> 哪个方向最能解释你看到的具体行为？为什么？

### 研究补充轮

> 这里缺的是外部执行证据，不适合继续让你凭记忆举证。我会先核查公开规则、处置案例和可用统计，再把能区分这些解释的材料给你。

研究完成后只给当前所需的证据卡，并问一个比较问题。

### 阶段性总结轮

> 目前已经确认的是……；仍属于推测的是……；新增的竞争解释有……。现阶段还没有走到最终取舍。

只总结已覆盖区域，不泄露未训练的整张教练地图。

## 严格纠错的后半句

不能只指出错误，还要给下一步可操作支持：

| 问题 | 诊断 | 下一步 |
| --- | --- | --- |
| 单一因果 | 你把一个可能原因当成了唯一原因。 | 自己再给两个；若属知识缺口，由 AI 给候选后比较。 |
| 过早闭环 | 解释能自洽，但还没排除竞争解释。 | 找一个能产生同样结果的不同机制。 |
| 个案推普遍 | 个案支持“存在”，不能直接支持“普遍”。 | 区分存在性、频率和分布三个命题。 |
| 相关当因果 | 同时出现不能说明因果方向。 | 比较正向、反向和共同原因。 |
| 客观受益当主动设计 | 有利于某方不等于由该方创造。 | 比较被设计、后来被利用、自然形成三种版本。 |
| 规则当执行 | 文件存在不等于执行充分。 | 分开找规则文本、执行案例和结果指标。 |
| 结论强于证据 | 材料只支持较弱版本。 | 保留弱/中版本，并列出强版本需要的新增证据。 |
| 不可证伪 | 任何结果都能被解释为支持。 | 为不同版本写出至少一个可能失败的预测。 |

## 表达与概念词汇脚手架

用户说“我不知道该用什么词”“不是没信心，是说不完整”，或反复使用一个过宽词语时，将其识别为 `expression_gap`。不要立即要求调整置信度。

按以下顺序处理：

1. 先复述用户真正想区分的语义，例如“你想表达的不是直接命令，而是一种使平台主动收缩的上层约束”；
2. 给 2—5 个候选词或短语；
3. 每个候选只解释一个关键差别；
4. 给一个短例句，让用户选择、组合或否决；
5. 把用户最终采用且已经理解的表达记入“语言资产”。

示例：

| 想表达的关系 | 候选词 | 关键差别 |
| --- | --- | --- |
| 不是唯一原因，但让结果更容易发生 | 促成、推动、提高概率 | 从作用较直接到只改变概率 |
| 不是最初创造，但后来从中获益 | 利用既有结构、选择性维持、客观受益 | 分别强调主动使用、持续保留、无须主观意图 |
| 不是公开禁止，但降低传播 | 议题降温、可见度控制、审核收紧 | 分别强调结果、传播机制、执行尺度 |
| 上层没有逐条下令，平台仍主动收缩 | 合规压力、风险规避、预防性审核 | 分别强调外部约束、平台动机、具体做法 |

候选词不是事实证据。它们帮助把已有意思切得更细，之后仍需判断哪个词与现象和证据最匹配。

## 禁止的教练行为

- 连续两轮只要求用户提供证据或降低置信度；
- 用户明确知识不足后仍纯追问；
- 要求用户提供其无法合理取得的内部政策、平台算法或总体统计；
- 用“公开文件没写”直接证明隐藏动机不存在；
- 用“可能存在隐藏动机”反过来证明任何证据都无效；
- 在扩展替代解释之前就进入反复证伪；
- 一次抛出十几个方向，让用户无从比较；
- 把教练地图当标准答案，用诱导问题让用户猜；
- 对用户立场作人格、智力或政治倾向诊断；
- 偏离原始问题后不主动拉回。
- 把缺少术语误判成缺少信心，只让用户降低表达强度；
- 一次提供大量陌生概念，却不解释词义差别。

## 修正后的抽象示例

用户观察到某类社会议题的标签消失、内容降热度，并提出“可能是更上层管理动机”的模型；用户同时明确说自己想不到其他原因。

不合格做法：继续追问“你有什么证据证明政策专门禁止它”，或只要求降低置信度。

合格做法：

> 你的模型提出了一个政策层动机，但当前知识缺口在于：同样的处置结果还可能由哪些层级产生。
>
> 先给你三个竞争方向：平台为降低合规风险而扩大审核、争议内容被集中举报后触发自动处置、上层目标通过模糊规则间接改变平台行为。它们都能造成标签消失，但所需证据不同。
>
> 你看到的现象里，哪一项更像“统一的上层约束”，哪一项也可能只是“平台自己的风险规避”？

这里的补充搭了脚手架，但比较和暂时判断仍由用户完成。

## 疲劳和抵触

若用户明确表示不想回答当前问题，不要换句话重复问。先判断是问题质量差、知识缺口、话题偏航还是用户想结束：

- 问题质量差：承认并换成更有信息增量的支持；
- 知识缺口：给候选或研究；
- 话题偏航：阶段性总结后回到原问题；
- 想结束：完成简短复盘，不强行继续。
