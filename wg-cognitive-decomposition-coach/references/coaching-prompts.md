# 追问、提示与纠错

按当前认知动作选一个问题即可。问题库不是一轮回复的清单。

## 渐进提示模板

### Level 0：纯提问

- “如果只保留确定知道的事实，还剩下什么？”
- “这一步为什么能推出下一步？”
- “这个结论依赖什么没有说出口的前提？”
- “同一个结果还有别的解释吗？”
- “什么反例会让你修改这句话？”
- “现有信息最多支持多强的结论？”

### Level 1：一个方向

- “先只看时间因素：短期效果和长期结果会不会不同？”
- “先区分个体经验和普遍规律。”
- “可以从资源条件想一个遗漏变量。”
- “想一想：影响因素和决定因素是否被混在了一起？”

### Level 2：半开放结构

- “有没有可能它缓解了一部分问题，但没有解决另一部分？这会怎样改变结论？”
- “A 和 C 同时出现，也可能由第三个变量 B 造成。这里的 B 可能是什么？”
- “即使这个因素有帮助，也未必足够。还缺什么条件？”

### Level 3：完整补充

先说明为何升级：“你已经尝试了两轮，下面我补全这一层，但下一层仍由你判断。”然后只补当前阶段，不顺带完成剩余所有阶段。

## 典型错误与追问

| 错误 | 一句诊断 | 后续问题 |
| --- | --- | --- |
| 单一因果 | 你把一个可能原因当成了唯一原因。 | 至少还有哪两个因素可能共同影响结果？ |
| 过早闭环 | 这条解释现在能自洽，但还没有排除其他解释。 | 哪种不同的故事也能解释同一事实？ |
| 个案推普遍 | 这里从一个个案跳到了一般规律。 | 需要什么样的样本才能支持群体结论？ |
| 相关当因果 | 同时出现还不能说明谁导致谁。 | 可能存在反向因果或共同原因吗？ |
| 结论强于证据 | 证据只支持“可能”，表述却到了“必然”。 | 把结论降一级，你会怎么说？ |
| 影响当决定 | 你证明了它可能有影响，还没证明它能决定结果。 | 即使这个因素存在，结果仍可能被什么改变？ |
| 未彻底解决即无价值 | 这里把“没有解决全部”推成了“完全无效”。 | 部分缓解与根本解决能否同时区分？ |
| 忽略时间 | 你的判断没有说明观察窗口。 | 换成短期或长期，结论会变化吗？ |
| 二元化判断 | 你把连续程度压成了对或错。 | 能否用概率、程度或条件重述？ |
| 第一解释偏见 | 第一个说得通的解释被提前当成答案。 | 什么证据能区分它和第二种解释？ |

## 用户卡住时

1. 先缩小任务：只检查一句、一个箭头或一个词。
2. 再给一个方向提示。
3. 再给二选一的结构差异，但不要暗示“标准选项”。
4. 用户仍明确要求补充时，才给当前阶段的完整示范。

不要连续追问到像审讯。若用户明显疲劳，可短暂总结已完成部分，再让用户选择继续或结束；总结仍不提前泄露未完成分析。

## 训练示例

用户：“一个人旅行很多但后来仍然痛苦，所以旅行可能只是在逃避问题。”

合格首轮：

> 你已经形成了“旅行—逃避—问题未解决—仍然痛苦”的因果链，但第一步到结论之间还缺验证。
>
> “旅行后仍然痛苦”，是否一定能推出“旅行从未缓解过痛苦”？

不合格首轮：立即罗列心理健康、童年经历、社会关系、经济条件、创伤事件等全部变量。即使内容可能正确，也剥夺了用户训练机会。

## 事实纠错

若训练材料包含可核验且关键的事实错误：

- 明确区分“材料事实不准”和“推理方法有问题”；
- 只纠正继续分析所必需的事实；
- 对不确定信息标注不确定，不以流畅叙述代替证据；
- 纠正后继续让用户检查：事实变化会让哪一步推理失效？
